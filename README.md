# PSCC
This is just a part of the code, just to verify the validity of the PSCC methodology

The variable named PSF.mat is generated by the method proposed in this paper for constructing PSFs.

The image named SeqImg.tif is a cropped screenshot of the central field of view from cycle 1 in the H channel, with a resolution of 1024 × 1024 pixels. It is provided for demonstration and method validation purposes.It is important to note that complete sequencing images typically contain sensitive biological information, such as chip identifiers, positional metadata, and traceable genetic features related to individuals. To protect privacy and comply with ethical and data security regulations, we have not released the full sequencing image. Instead, we provide a cropped and de-identified section from the central region of the image, which does not contain any identifiable content but is sufficient for method validation and reproducibility.

The file main.m serves as the main script for image restoration experiments in this study. It provides a complete implementation of the Richardson–Lucy deconvolution process using the provided point spread function (PSF) and the original image to generate the restored image.In the experiment, we present a visual comparison between the original and restored images, and further plot their power spectrum projection curves along both the X and Y directions. Based on these curves, we calculate the mean absolute error (MAE) and correlation coefficient (CC) to quantitatively evaluate the restoration performance in terms of bidirectional power spectrum projections. This script is intended to validate the effectiveness of the image restoration method.
It should be noted that the base-calling algorithm used for gene sequencing images is proprietary and cannot be disclosed at this time. As a result, this script does not include the computation of Q30 or base-specific signal-to-noise ratio (SNR) from the restored images.
